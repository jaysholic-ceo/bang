# 에이전트에게 일 시키는 문구 모음

안티그래비티 같은 코딩 에이전트에게 개편 작업을 시킬 때 복사해서 쓰는 문구입니다. 에이전트는 먼저 `AGENT_INSTRUCTIONS.md` 를 읽게 됩니다(루트 `AGENTS.md` 가 없으면 아래 문구의 첫 줄이 그 역할을 합니다). 배경은 `README.md` 에 있습니다.

작성 2026-10-06. 저장소 브랜치는 `ui/ux-refresh-2026-10` 입니다.

## 쓰는 원칙

- 한 요청에 한 항목만 시킵니다. `README.md` 4번 표의 ID(FAC, HERO, DOC, NEWS 등) 단위입니다. "전부 적용해줘"는 쓰지 않습니다.
- 수정 전에 계획을 먼저 보고하게 하고, 확인한 뒤에 실행시킵니다.
- 안티그래비티에 터미널 명령 자동 실행 설정이 있으면 "검토 후 실행"으로 둡니다. 푸시·삭제 금지는 지침으로만 막는 것이라, 설정으로 한 번 더 막아 둡니다.
- 작업이 끝나면 직접 `git status` 로 바뀐 파일을 보고, 괜찮을 때 "이 변경을 커밋해줘"라고 따로 시킵니다. 처음 한두 번은 보고를 믿지 말고 화면을 직접 열어 봅니다.

## 1단계. 점검만 (수정 금지)

가장 먼저 시킵니다. 지침을 실제로 지키는지도 같이 확인됩니다.

```
docs/design-handover/AGENT_INSTRUCTIONS.md 지침대로, 이번에는 파일을 수정하지 말고 점검만 해줘.
1) 현재 브랜치와 git status 를 보고해줘. 이미 있는 변경(HomeClient.tsx 등 수정 파일, src/components/home, src/lib/clinic.ts, docs/design-handover, fix_hero_video.py, "Claude outputs" 폴더)은 앞서 해 둔 것이니 건드리지 마.
2) npm run build 와 npm run lint 를 실행해서 결과를 알려줘. 기존 경고와 새로 생긴 오류를 구분해서.
3) docs/design-handover/README.md 4번 표에서 "납품 파일 없이 코드만으로 지금 할 수 있는 항목"과 "납품을 기다려야 하는 항목"을 나눠서 알려줘.
```

## 2단계. 코드 준비 작업 (한 번에 하나)

납품 파일 없이 지금 할 수 있는 일입니다.

- FAC: 시설 사진이 없을 때 16:9 자리표시를 보이게 하는 처리
- HERO: 히어로 영상 뒤에 정지 이미지를 넣을 자리
- NEWS: 뉴스 상세의 폴백 로고 경로 정리

시설 건을 예로 든 문구입니다. 다른 항목은 ID와 설명만 바꿔서 씁니다.

```
docs/design-handover/AGENT_INSTRUCTIONS.md 지침대로 작업해줘.
README.md 4번 표의 FAC-01~06 중 코드 부분만 해줘. 시설 사진이 없을 때 16:9 자리표시 카드가 보이게 하는 처리야.
- 먼저 어느 파일의 어느 부분을 어떻게 바꿀지 계획만 보여주고, 내가 OK 하면 수정해줘.
- 지금 있는 임시 일러스트 SVG 파일은 지우지 말고 그대로 둬.
- 색은 tokens.json 만 쓰고, 문구가 필요하면 새로 만들지 말고 나에게 물어봐.
- 끝나면 바꾼 파일 목록, npm run build 결과, /intro 의 데스크톱(1440)·모바일(390) 화면 확인 결과를 보고해줘. 커밋은 하지 마.
```

## 3단계. 납품 파일이 왔을 때

파일을 `public/` 의 지정 위치(`design-system/04-delivery-spec.md` 의 이름·위치)에 먼저 넣은 뒤 시킵니다.

```
docs/design-handover/AGENT_INSTRUCTIONS.md 지침대로 작업해줘.
납품 파일을 넣었어(목록: ...). README.md 4번 표의 (ID) 항목만 적용해줘.
1) 04-delivery-spec.md 와 05-checklist.md 기준으로 파일 규격(형식, 해상도, 용량, SVG 규칙)을 먼저 검사해서 결과를 알려줘. 어긋나면 적용하지 말고 멈춰.
2) 통과하면 코드의 경로만 교체해줘. 색, 구성, 문구는 바꾸지 마.
3) 쓰지 않게 된 임시 파일은 지우지 말고 목록만 알려줘.
4) npm run build 결과와 해당 페이지의 1440·390 화면 확인 결과를 보고해줘. 커밋은 하지 마.
```
