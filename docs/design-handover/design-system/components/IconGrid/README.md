아이콘 격자는 부위 그룹 5종(ICON-G1~5)과 질환 9종(ICON-D1~9), 모두 14개를 한 사람이 그린 한 벌로 보이게 하는 제작 시트와 크기 규칙입니다.

소비하는 쪽이 준비할 것은 병원 의료진이 감수한 해부학 모티프이고, 모티프 표는 "아이콘 세트" 문서에 있습니다. 미리보기의 도형은 형식 샘플일 뿐 아이콘이 아닙니다.

- 48×48 격자에 선 `icon-stroke`(2.5px), 안쪽 여백 `icon-inset`(4px), 끝과 모서리는 둥글게 그립니다. 24px 최적화판은 격자 24에 `icon-stroke-24`(2px)입니다.
- 선은 `slate`, 포인트는 `copper` 한 곳, 면은 `copper-tint` 또는 `white`입니다. 이 네 색 밖의 색은 쓰지 않습니다.
- 40px(모바일)과 24px에서 부위를 알아볼 수 있어야 합니다. 아이콘마다 두 크기를 나란히 놓은 확인 시트를 납품합니다.

- 파일 이름은 icon-part-spine.svg, icon-disease-disc.svg 형식입니다.
