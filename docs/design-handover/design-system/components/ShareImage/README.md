공유 이미지(OG-01)는 링크를 카카오톡·네이버·문자로 공유할 때 맨 먼저 보이는 1200×630 JPG의 구성 규칙입니다.

소비하는 쪽이 준비할 것은 병원이 승인한 한 줄 문구, 역색판 로고 원본(LOGO-02), 오른쪽에 넣을 사진(기존 시안의 대표원장 사진, 원본 파일이 오면 교체)입니다. 글자만 있는 A안과 사진을 넣은 B안을 모두 납품하고 병원이 하나를 고릅니다.

- 배경은 `slate`, 병원 이름은 `asset-title`(Noto Serif KR 56px 이상, `white`), 이름 아래에 `copper-light` 구리 선(48×3), 그 아래 한 줄 설명은 `white` 28px입니다. "서울 강북구 수유동 · 비수술 통증 진료"는 사이트 메타 설명에 이미 있는 표현이라 그대로 씁니다.
- 핵심 요소는 중앙 1000×500 안에 둡니다. 메신저의 1:1 크롭(x 285~915)에서도 병원 이름이 온전히 보여야 하므로, 이름은 이 안에 두고 두 줄("지인마취통증의학과" / "강북점")로 나눕니다.
- 오른쪽 사진(B안)은 x 930~1200, 전체 높이의 직사각형 한 칸에 넣고 `slate` 45% 덮개를 평면으로 올립니다. 그라데이션과 흐림은 쓰지 않습니다. 이 칸은 1:1 크롭(x 285~915) 밖이라 크롭되면 사진이 빠지고 글자만 남습니다. 사진이 없을 때는 글자만 있는 A안을 씁니다.
- B안의 사진은 기존 시안(확정 개편 캡처)의 대표원장 사진이며 484×646 화면 해상도 그대로 높이 630에 맞춰 약 3% 줄여 넣었고 확대하지 않았습니다. 얼굴이 칸 가운데에 오도록 가로 위치를 잡았습니다. 원본 파일이 오면 같은 위치로 교체합니다.
- 전화번호, 후기, 수치, "최고", "전국 80만 명" 같은 광고성 문구는 넣지 않습니다.
- 납품은 JPG 300KB 이하, 파일은 public/og-image.jpg이고 1:1 미리보기도 함께 확인해 보냅니다.
