진료 시설 이미지 자리(FAC-01~06)는 병원 소개의 시설 안내 카드 6장에서 사진이 들어갈 16:9 슬롯의 규칙입니다. 일러스트는 그리지 않고 위치와 상태만 정합니다(2026-10-02 결정).

소비하는 쪽이 준비할 것은 공간 이름(사이트에 이미 있는 이름)과, 병원이 찍어 주는 실제 사진입니다. 사진이 오기 전에는 자리표시 상태로 둡니다.

- 비율은 16:9로 고정합니다. 사진이 늦게 떠도 같은 크기의 자리가 먼저 잡혀 화면이 밀리지 않습니다.
- 자리표시 상태는 `bg-surface` 바탕 가운데에 사진 글리프 하나(44px, 색 `slate-muted`)만 두고 글자는 쓰지 않습니다. 공간 번호·이름·설명이 카드 아래에 이미 있어 슬롯 안에 이름을 다시 쓰지 않고, 테두리도 카드가 갖고 있어 슬롯에는 따로 두지 않습니다(카드 밖에서 단독으로 쓸 때만 `hairline` + `border-hairline`). 이미지 불러오기에 실패해도 깨진 이미지 아이콘 대신 같은 상태를 보여 줍니다.
- 사이트 구현(Matt, 2026-10-06)은 16:9, #EEF0F2(`bg-surface`와 같은 값), 가운데 이미지 아이콘 44px, 선 1.5, 글자 없음입니다. 선 두께 1.5는 24 단위 뷰박스 값이라 44px에서 실제 약 2.75px로 그려집니다. 토큰 `icon-stroke` 2.5(48 격자)를 44px로 줄인 환산값(약 2.3px)보다 약간 굵지만, 임시 표시라 그대로 두기로 했습니다(Matt, 2026-10-06). 새 토큰이 아니라 이 자리표시에만 둔 예외이며, 미리보기도 이 값으로 그립니다.
- 사진 카드는 16:9 중앙 크롭이고, 가장자리 5% 안쪽(안전 영역)에 핵심 피사체를 둡니다. 5%는 제안값이라 확정이 필요합니다.
- 3:2로 촬영하면 16:9로 자를 때 위·아래 각 약 7.8%가 잘립니다. 촬영 때 가장자리에 중요한 것을 두지 않습니다.
- 6장 모두 같은 색보정(밝기·색온도 통일)을 거치고, 환자 얼굴·차트·약품 라벨 같은 식별 정보는 미리 지웁니다.
- 로비(FAC-01) 임시 일러스트 샘플 1장은 만들어 두었고 쓰는 것은 선택입니다. 쓰는 동안만 "실제와 다를 수 있습니다" 안내를 붙이고, 나머지 5장 일러스트는 만들지 않습니다.
