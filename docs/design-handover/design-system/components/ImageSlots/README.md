의료진 초상, 뉴스 기본 이미지, 영상 카드 기본 이미지가 들어갈 자리의 비율과 위치 규칙입니다. 그림은 그리지 않고, 사진이나 썸네일이 없을 때 보이는 틀만 정합니다.

소비하는 쪽이 준비할 것은 로고 심볼이 만들어진 뒤의 Z 선화입니다. 의료진 사진은 기존 원본을 그대로 쓰므로 새로 준비할 것이 없습니다. 실제 YouTube 썸네일이나 기사 이미지가 있으면 그것이 우선이고, 이 틀은 없을 때만 보입니다.

- DOC-01~03은 4:5 세로 틀에 기존 원본을 그대로 넣습니다. 배경은 사진 고유의 색을 바꾸지 않고, 틀 바탕 `bg-surface`는 사진이 늦게 뜰 때만 보입니다. 사진별 크롭 창과 표시 크기 상한, 머리 위치 기준은 DocFrame에 있습니다. 같은 파일을 소개 카드·상세·홈 철학 섹션에 함께 쓰므로 머리 둘레가 잘리지 않게 합니다.
- NEWS-01은 16:10(1600×1000), `bg-surface` 바탕 가운데에 Z 심볼 선화를 큰 워터마크로 두며 투명도 12% 이하, 글자는 없습니다.
- MEDIA-01은 3:2(1200×800), 같은 바탕에 "영상 보기" 재생 아이콘을 가운데, 분류 라벨(방송·세미나) 자리를 왼쪽 위에 둡니다.
- 세 자리 모두 비율을 고정해 사진이 늦게 떠도 화면이 밀리지 않게 하고, 단독으로 쓸 때 테두리는 `hairline` + `border-hairline`입니다(카드 안에 들어가면 카드 테두리가 대신합니다).
- 의료진 크롭 위치는 저장소 원본으로 잰 값으로 확정했고(DocFrame), 머리 위치 참고값은 실제 사진 3컷에서 쟀습니다. 라벨 위치는 브리프에 수치가 없어 제안한 값입니다.
